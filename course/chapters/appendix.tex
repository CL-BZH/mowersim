\section{Running the code}

The package needs Python 3.10 or later, NumPy, Matplotlib and Shapely (and
Pillow for animations). From the root of the repository:

\begin{verbatim}
pip install -e ".[gif,test]"
python -m mowersim mower                      # the mower, top view
python -m mowersim show lawns/garden.json     # a lawn and the mower
python -m mowersim path 0 0.92 180 --compare  # Dubins vs Reeds-Shepp
python -m mowersim demo lawns/rectangle.json --png demo.png
python -m pytest                              # the tests
python tools/course_figures.py                # redraw the figures
\end{verbatim}

The dimensions and speeds of the mower are in \code{mower.json}; any command
accepts \code{-{}-mower my\_mower.json}. To use another machine, measure:

\begin{description}
  \item[The minimum turning radius.]
    \leavevmode\\
    Drive a full circle at full lock and measure the diameter of the circle
    traced by the middle of the rear axle; half of it is $\Rmin$. In the file,
    set \code{max\_steer\_deg} so that $L/\tan\delta_{\max} = \Rmin$.
  \item[The deck.]
    \leavevmode\\
    The distance $d$ from the rear axle to the centre of the deck, the
    cutting width, and the number and position of the blades.
  \item[The speeds.]
    \leavevmode\\
    Forward on straight lines and in turns, in reverse, and the time to stop,
    change gear and start again.
\end{description}
